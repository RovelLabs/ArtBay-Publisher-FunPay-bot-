# Security Policy / Политика безопасности

## Reporting / Сообщение об уязвимости

Please do not publish working exploits, account cookies, Telegram tokens, or
other users' data in a public issue. Contact the maintainers through the
RovelLabs GitHub organization and include reproducible steps with all secrets
redacted.

Не публикуйте рабочие эксплойты, cookies аккаунта, Telegram-токены или чужие
данные в открытом Issue. Свяжитесь с сопровождающими через организацию
RovelLabs на GitHub и приложите воспроизводимые шаги, предварительно удалив
все секреты.

## Supported version / Поддерживаемая версия

Security fixes are provided for the latest published release. At the moment,
that version is **4.0.3**.

Исправления безопасности выпускаются для последней опубликованной версии.
Сейчас это **4.0.3**.
